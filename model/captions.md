# Model stills: captions

Our own renders from the Blender model `clipper_site_v2_plat_features.blend`, made 20 Nov 2026.
The .blend file is not in the repo because it carries parcel owner labels.

For these renders: the parcels layer and its owner colors were hidden, the general roads layer was hidden,
the station marker pins (which include our own coordinate inference) were hidden, and the ground was made
partly see-through so the tunnels show. The file was not saved with any of these changes.

Everything in the model is approximate. The tunnels are traced from DGGS (Alaska Division of Geological and
Geophysical Surveys) OFR (Open-File Report) 157 Plate 1, 1982. The plat features are traced from the USMS 2493
plat, recorded 2001. Buildings are traced from the FNSB (Fairbanks North Star Borough) 2023 aerial. The ground is
FNSB and USGS 2017 LiDAR (laser scanning).
